# Labbaik Perfume - AI Era Catalog

A professional, minimal fragrance catalog designed for the modern web.

## Deployment
1. Upload all files (`index.html`, `style.css`, `script.js`, `logo.png`) to a GitHub repo.
2. Connect the repo to **Vercel**.
3. It will be live instantly.

## Design Highlights
- **Orbit Animation**: A CSS-powered rotating ring around the logo.
- **Glassmorphism**: Translucent, frosted cards for a premium feel.
- **AI Glow**: Subtle radial background gradients.
